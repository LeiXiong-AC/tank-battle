# 🎮 坦克大战 (Tank Battle)

经典坦克大战游戏的 Web 版实现，使用纯 HTML5 Canvas + JavaScript 开发，无需任何依赖。

## 在线游玩

直接用浏览器打开 `index.html` 即可游玩。

## 游戏操作

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格键` | 发射子弹 |
| `P` | 暂停/继续 |

## 游戏规则

- 消灭所有敌方坦克即可通关，进入下一关
- 保护屏幕底部的**基地**（★），基地被摧毁则游戏结束
- 玩家共有 **3 条生命**，被敌方子弹击中则失去一条
- 随关卡增加，敌人数量更多、速度更快

## 地图元素

| 图标 | 说明 |
|------|------|
| 🟫 砖块 | 可被子弹摧毁 |
| ⬜ 钢铁 | 无法被子弹摧毁 |
| 🟦 水域 | 坦克无法通行 |
| ★ 基地 | 保护目标，被摧毁则游戏结束 |

## 技术栈

- **HTML5 Canvas** — 游戏渲染
- **原生 JavaScript** — 游戏逻辑（无框架依赖）
- **CSS3** — UI 样式
